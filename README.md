# AICO Vision lisans listesi

Bu depo yalnızca **şifreli ve imzalı** lisans kayıtlarını içerir. Kayıtlar yalnızca ilgili lisans
anahtarının sahibi tarafından çözülebilir; müşteri bilgisi, süre ya da durum bu depodan okunamaz.
Dosyalar lisans yönetim aracı tarafından otomatik üretilir, elle düzenlemeyin.
